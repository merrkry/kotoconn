# Drive TUN queues and connections independently

A TUN endpoint supervises one task per queue. Each task polls independent receive/dispatch and transmit futures, so a pending writer does not block reception. Readiness wakes that queue directly through Tokio; the supervisor handles worker exits and shutdown, without polling descriptors or carrying packets. A stable hash of protocol, source and destination assigns each flow to one worker; that worker owns its dispatch maps and sends replies through its own queue. A packet arriving on a different queue moves through a bounded channel. On Linux, writes teach TUN the queue for subsequent packets of that flow, reducing forwarding after admission. Receive buffers, GRO state and transmit buffer pools have exclusive owners. Each TCP connection still owns a smoltcp interface, socket and Tokio driver, with bounded duplex buffers and independently tracked FIN/RST cleanup.

Every fragment, including the first, hashes to a reassembly worker before transport dispatch: IPv4 uses source, destination, protocol and ID; IPv6 uses source, destination and ID. Including the protocol in the IPv6 key would separate conflicting fragments that must poison the same assembly. smoltcp owns IPv4 reassembly; the IPv6 path uses its wire types and Assembler. A completed datagram moves to its flow owner if necessary. Ordinary packets bypass reassembly storage. Workers share admission permits, queued-byte budgets and reassembly slots; expiry releases shared capacity even on idle workers. Only UDP encoding shares a short synchronous lock, preserving outgoing fragment IDs across writers. It releases the lock before any device I/O. Each queued UDP reply remains a complete datagram.

Queue membership is fixed until the inbound stops, so ownership cannot migrate during a connection or fragment assembly. Stopping ends UDP associations and stops TCP admission. The supervisor keeps workers alive until existing TCP drivers drain, then lets transmit queues empty; forced cancellation interrupts blocked I/O. A worker failure or an aborted endpoint cancels that inbound's connections and releases all queues without cancelling other inbounds. TUN binding reports its interface name through the same inbound binding boundary used by socket listeners.
